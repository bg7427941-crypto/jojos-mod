# JoJo's Mod 0.14.1-alpha.1 — audio del anime

[Descargar JAR](https://github.com/bg7427941-crypto/jojos-mod/raw/refs/heads/main/releases/0.14.1-alpha.1/jojosmod-0.14.1-alpha.1-anime-alpha.jar)

Esta es la alpha validada con las 25 grabaciones habituales de ataques y paradas
temporales. El JAR incluye créditos, licencias y manifiestos de procedencia.

Requiere **Minecraft 26.3, Java 25, NeoForge 26.3.0.95 y GeckoLib 5.5.7**.
Cliente y servidor usan **protocolo 13**. Coloca este JAR y GeckoLib en `mods/`,
sustituyendo el JAR anterior de JoJo's Mod. Las partidas se conservan.
